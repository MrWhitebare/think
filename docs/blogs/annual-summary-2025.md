# 2025年年度总结

## 个人生活方面

今年的开始，无疑是一个令人开心的时刻。
我遇到了一个让我感到快乐的人，我也一度以为，自己同样能够带给她快乐。

我试着用很多精力去向她表达我的爱与喜欢。我努力去学习吹奏《泪桥》，也试着从更深的层面理解她，想走进她的内心。我以为，只要足够真诚、足够用力，就能靠近她一些。

但在真正见面之后，我发现一切似乎都发生了变化。

我原本以为她是一个单纯可爱的人，送我可爱的艺术画和愿意回到我所在的城市工作，和我分享日常。

我们第一次因为她想换工作，我没有完全站到她的立场而吵架时，她说：“她只是因为找工作的计划才会重新回来这里，我只是很少很少的一部分”。那时我哭了，她很简单的安慰了我一下，告诉我不要多想，但是往后的一周中都不咋理我。

后面她感冒了，我给她买了药。然后我约她去听脱口秀，她在饮料机旁边抱了我一下，但是当脱口秀主持人问今天谁和情侣来的，她连举手都不愿意还有一副抗拒的表情，我心中有点儿难受。

再到我们去了别的城市旅游，我们玩得比较开心，一起吃了美食，但是后面因为我拍的照片不是很好而有点责怪我。我告诉她，我更喜欢和她在一起的时刻，拍照并不重要，重要的是身边的人。后面她告诉我说如果那时我向她告白，她就会同意了，可是我之前说开一个情侣树，她都不愿意啊。给我一种感觉是——我总是差一步就能达到她心中的要求了，但是我总是没法满足她的要求。

旅游后的一周，我们说话很少，好像我们一直不在一个频道上，我感兴趣的她不感兴趣，我好像从未交流过。周末时，她和她的朋友们在玩真心话大冒险，她说想我了，但我提出去找她，她又说别来了，她们在玩游戏。诶，我有点难受，我怎么感觉我被玩弄了。

最终，她先一步失去了耐心，说了再见。我很痛苦，我彻夜的睡不着，工作也没有状态。

从那以后，我开始对“爱”本身产生了深刻的怀疑。
喜欢一个人，难道不是应该接纳他的全部吗？
为什么对朋友可以有耐心，却对的“恋人”反而更加冷漠？
为什么不断拉扯，却迟迟不愿意确认关系？
为什么我遇到的人，连一个真正的开始都不愿意给我？

我灰心丧气，整个人状态很差，甚至曾想过离开工作的地方。合租的房子又让人烦躁——隔壁是一对中年夫妻，他们经常在凌晨一点多洗澡，那噪音让我几乎撑不下去。

那段时间，我请妈妈来陪我。我发现她很容易满足，只要有人对她好，她就会感到快乐和幸福。于是，我和妈妈一起去了烟台，见了十多年未见的亲戚。小姨请我们吃了丰盛的海鲜大餐，又沿着海岸线带我们慢慢游览。海风、海浪，还有亲人的笑声，让烦恼仿佛远去。

我们还去了长岛，惬意地躺在月牙湾的鹅卵石上，什么都不想，只是看着远处蔚蓝的大海，感受阳光洒在身上。妈妈像个孩子一样，在海边尽情玩耍，脸上洋溢着纯粹的快乐。

后来，我们坐上了邮轮，海风拂面，远处的海岛若隐若现，空中海鸥盘旋飞翔。望着这一切，我的心渐渐平静下来，所有的烦恼仿佛都随风而去。

## 工作成果

### 使用rspack+swc重写公司脚手架

我们公司原有脚手架使用 `Webpack` + `babel`，但是随着代码越来越多，引入的第三方库越来越多，编译与热启动速度越来越慢，有好多次耽误我下班🤣 忍不了一点儿。

于是我决定使用 `rspack` 重写公司前端脚手架，刚开始我只是让`chatgpt`或者`doubao`来帮我改。慢慢地我可以将脚手架运行起来了，然后，我的完美主义倾向犯了，我觉得脚手架还不够快，之后我就替换babel、去掉eslint、引入swc、支持别名引用、支持tailwindcss、，区分生产依赖和开发依赖、使用optimization chunks 拆分代码、使用biome来进行代码校验。

制定启动规则

```shell
pnpm dev #开发环境
pnpm build #打包
pnpm preview #生产产物预览
```

后面效果还是很不错的，比较差的电脑热启动和打包速度也很快，生产产物小了$\frac{2}{3}$，开发体验有了质的飞跃。

### 前端和后端界限的突破

本年度负责了很多对接工作，例如提供三方接口，对接rocketmq消息队列、甚至完整springboot后端数据同步项目，还践行了很多设计模式中的内容。

在我看来，突破了前端和后端的界限，不在局限于某一个领域，看待问题更加全面。

## 感受与得失

真实的表达自己的内心，不喜欢说出来就好了，不用强求自己，也不要强求别人。要离去的人，我们也留不住。一段好的感情是双向奔赴的，不是让另一个人感到消耗和疲惫，不开心了不要忍着不说，不要害怕失去就选择放弃自己的底线。

一定要拥有自己的底线，不要害怕失去，自己的感受是很重要的。
