# 糟糕的一天

今天心情很糟，感觉今天自己做了很多事情，但是很多事情都没有做好。一下子在配置数据，一下子在开发前端，一下子又处理别人的流程，还有处理新的项目bug需要查看。啊，突然变得好累好累，为啥我要在这样一家公司呆着，啥都要做。真的好累好累啊。

我发现我会陷入一种愤怒的逻辑中，在这个逻辑中我很难听到真正的需求是啥，真正的痛点是啥。假装自己是理性，实际上我现在非常不理性，只想推卸责任和吵架。

我有时候在想很多环境的问题，我有时候也会怀疑自己。是不是我太容易愤怒了，反正现在就是好想好想离职，不干了。我就想逃避，理性告诉我——骑驴找马。但是我有时候也很不理性。

我很不喜欢这样，一天干很多的事情，这天过去后，我都不知道怎么做了什么；我内心现在深深的知道，我已经很讨厌这份工作了，很影响我的心情，我在想同事为啥都那么固执呢，还是说我自己很固执，所以才会觉得他们是很固执的。欸，既然我逐渐感受不到自己的价值了，那么应该要离开了。

我本来挺想找朋友来倾诉的，可是转念一想，还是不说了，万一他们也心情不好呢，没有人非得要安慰我。
