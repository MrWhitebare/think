# Java学习计划

## 80% 的防御性技术（Java/高并发/微服务面试突击）

目标： 搞定上海大厂（如携程、汇丰、字节分部）的面试。

### 1. 推荐资源

- Java 并发（JUC）：B站搜“尚硅谷周阳 JUC”或“代码随想录”。只看线程池、CAS、锁、AQS这四个核心。

- 微服务：B站搜“黑马程序员 Spring Cloud Alibaba”。重点看 Nacos、Sentinel（限流）、和分布式事务 Seata。

- MySQL/Redis：搜“小林coding”的图解文章（必看！）。他把索引原理、Redis缓存雪崩等讲得非常透彻。

- 算法：LeetCode 热题 100。重点练：双指针、哈希表、二叉树。

### 2. 学习计划（4-6周）

- Week 1-2 (Java/JUC/Redis)：背熟线程池 7 参数，理解 Redis 为什么快（IO多路复用），掌握分布式锁实现。

- Week 3 (微服务/分布式)：理解 Spring Cloud 的核心闭环，搞懂配置中心和注册中心。

- Week 4 (面试算法与场景)：每天 2 道 LeetCode 中等题，背几个高并发场景（如秒杀系统设计）的模板。

## 第二部分：20% 的攻击性技术（AI Agent 赋能 Java）

目标： 在简历中加入“AI Agent”标签，面试时对面试官进行“降维打击”。

### 1. 推荐资源

- 框架：LangChain4j。这是 Java 版的 LangChain，它是你把 AI 接入 Java 微服务的唯一指定武器。直接看它的官网文档或 GitHub 示例。

- 核心理念：

    - Function Calling：学习 LLM 如何调用你写的 Java 接口;

    - RAG：学习如何用向量数据库（如 Milvus 或 Pinecone）让 AI 读懂你们公司的私有业务文档。

- 入门博主：在掘金或知乎搜“Java AI Agent 开发”，找那种带代码的项目实操。

### 2. 学习计划（2-3周）

- 上手 Demo：用 Spring Boot + LangChain4j 写一个“智能客服 Agent”。它能自动调用你本地的数据库接口查订单，并用自然语言回复。

- 简历包装：学习如何描述这个项目（例如：“利用 LangChain4j 实现了基于 Function Calling 的自动化业务助理，降低人工处理成本 30%”）。

## 第三部分：推荐一个“融合型”实战练习题

尝试做一个“智能日志分析 Agent”：

- Java部分：写一个微服务接口，读取分布式系统的异常日志。

- AI部分：接入 Agent，当日志报错时，AI 自动根据异常栈分析原因，并给出修复建议，最后通过 Webhook 发送到钉钉或飞书。

价值：这个项目不仅证明你会 Java 读日志、流处理，还证明你会 AI 赋能运维

## 6种最常用的设计模式

- 策略模式 (Strategy)：（必学） 消灭业务代码里恶心的 if-else，全栈工程师最爱。

- 工厂模式 (Factory)：（必学） 解决“怎么创建对象”的问题，Spring 的核心。

- 单例模式 (Singleton)：（必学） 理解面试常考的“双重检查锁”和线程安全。

- 代理模式 (Proxy)：理解 Spring AOP（日志、事务）是怎么实现的。

- 观察者模式 (Observer)：理解前端的 Vue 响应式原理，以及后端的事件驱动。

- 模板方法模式 (Template)：理解为什么你继承一个类，重写几个方法就能跑起来。
