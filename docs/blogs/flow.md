# 流程引擎

## 发起人节点

代表流程的发起者。它标识了一个角色—— **所有人** ，这意味着发起流程的角色可以是任何人。

## 添加审批方案

* **默认方案** ：这一分支的标签是"优先级1"，提示这个分支是默认的审批流程，设置了一些条件或操作。
* **方案2** ：另一个分支被标记为"优先级2"，这可能代表另一个审批方案，具有不同的条件或操作。

## 审核人节点

对于上一个条件进行审核

## 流程结果

这个节点是所有流程结束时的汇总或结论

## 总结：

* **角色定义** ：发起人和审核人是关键角色，发起人启动流程并选择审批方案，审核人负责最终的审批。
* **决策节点** ：流程中有两个审批方案（默认方案和方案2），可能用于不同的业务需求或审批路径。
* **节点关系** ：所有流程最终都会汇聚到一个“流程结果”节点，表明流程结束。
* **操作选项** ：流程中包含了多个操作节点，可能用于更细化地控制流程走向。
