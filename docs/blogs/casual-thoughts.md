# 随想

从年龄上看，我可能已经是一个成熟的人，可能在社会的定义上看，我可能需要结婚生子。但是我现在没有一点儿感觉，我也不想找对象，也对结婚提不起兴趣。

我亲眼见证了朋友的爱情，他们8年长跑最终结婚。我知道这个世界上存在爱和吸引。但是我又为自己而感到悲哀，我能遇到自己的爱吗？她是什么样的一个人呢。我其实渐渐的明白，爱不是一厢情愿，它是两个人的事，它是相互的。而我所在关系中，我从没遇到过如此的关系，不论怎样都是我都会感觉到不平衡和消耗，最终分手不可避免。

我不在乎世俗意义上的成功，我有自己追寻的东西，比如做一个技术很强的人。我希望有人可以看见我，我希望我不是因为结婚而结婚。这次婚礼上，新娘说：“婚姻并不一定通往幸福之路”。我深以为然，我希望通往幸福之路后，再通往婚姻。

还有曾经那么熟悉的朋友，如今我感觉很陌生。不论从那一点来看，都是这么陌生，甚至说一句客套话——我以后去北京找你。可是你之前来也并没有找我。可能不联系了，友情渐渐的就消失了吧。

记忆过往，我们很快乐，但是如今我们是如此的陌生了。我们下次的联系会只是一次微信上的彩礼钱吗。不过也不一定，我一直也预感自己不会结婚。或许我们不能再见了。

我明年要开始新的职业生活了，我不想在一趟死水中继续了。希望我们还能再见。我不希望结婚生子后，我这一生就结束了。死于30岁，埋葬于几十年后。
